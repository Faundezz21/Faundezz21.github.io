    Vortex Booking

    Sistema de reservas de salas de estudio universitarias con calendario semanal y diario, check-in por QR en cada puerta, liberación automática por inasistencia y lista de espera.

    • Evita reservas superpuestas en tres capas: validación, transacción con bloqueo pesimista y restricción EXCLUDE USING gist en PostgreSQL
    • Job programado que libera las reservas sin check-in a los 15 minutos y avisa por correo a la lista de espera
    • Feed iCal privado para Google Calendar, Outlook y Apple Calendar, y afiche imprimible con el QR de cada sala
    • Panel de administración con métricas de uso y tasa de inasistencia, policies por rol y notificaciones en cola
    • 79 tests de feature con PHPUnit sobre PostgreSQL y CI en GitHub Actions
    Laravel 13Livewire 4PostgreSQLTailwind CSSDockerGitHub Actions

    Vortex Insight

    Pipeline de datos y dashboard en Power BI sobre las órdenes de compra del Estado de Chile 2019–2025: 12,8 millones de órdenes y cerca de 60 GB de CSV de ChileCompra, convertidos en un modelo limpio, deflactado y auditable.

    • Responde cuánto compra el Estado sin competencia, dónde se concentra el gasto y qué tan concentrado está en pocos proveedores
    • Descarga, limpieza mes a mes y modelo en Parquet con Pandas, con cada decisión de limpieza documentada
    • Montos deflactados con el IPC del INE y detección de errores de moneda y outliers con revisión manual trazable
    • Hallazgos como el alza del trato directo en pandemia y la concentración del rubro combustibles medida con el índice HHI
    PythonPandasParquetPower BIDAX
    Proyecto personal · Open source · v7.10.1 GitHub ↗

    VortexCore Hub

    Centro de control y telemetría de hardware para Windows 10 y 11: una alternativa liviana a OMEN Gaming Hub, Armoury Crate o Lenovo Vantage. Solo muestra datos reales y funciona con el aislamiento de núcleo de Windows 11 activado, sin drivers vulnerables.

    • Backend en Python con API HTTP local e interfaz web en HTML, CSS y JavaScript sin frameworks, dentro de una ventana WebView2
    • Control de ventiladores y perfiles térmicos por WMI para HP, Acer, Lenovo, ASUS y Dell, y modo universal para el resto de notebooks
    • Telemetría en vivo de CPU por núcleo, GPU, RAM, batería y red, con medidor de latencia y selector del DNS más rápido
    • API protegida contra CSRF y DNS rebinding, con validación de todos los parámetros
    • 48 pruebas unitarias y CI/CD en GitHub Actions que compila el instalador y publica cada versión
    PythonJavaScriptWMI · PowerShellWin32 APIPyInstallerGitHub Actions

    Vortex-Screen

    Aplicación de escritorio para Windows que muestra y controla un teléfono Android desde el PC, hasta 120 FPS con audio en tiempo real. Desarrollé la interfaz y toda la automatización sobre el motor de código abierto scrcpy.

    • Dock lateral propio en Python y Tkinter, dibujado en Canvas con íconos vectoriales y efectos al pasar el mouse
    • Grabación en MP4, capturas, envío y descarga de archivos, e instalación de APK arrastrándolos a la ventana
    • Fija la pantalla del teléfono en 120 Hz mientras está abierto y la restaura al cerrar, vía ADB
    • Detecta cuando el fabricante bloquea el control remoto (Xiaomi, OPPO) y cambia solo a mouse y teclado virtuales (UHID)
    PythonTkinterADBWin32 APIscrcpy

    • Panel de administración con ingresos, ticket promedio, ventas de 7 días, stock bajo y ajustes masivos de precios
    • Registro, sesión, seguimiento y cancelación de pedidos con server actions
